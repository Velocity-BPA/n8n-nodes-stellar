# Automate Stellar Blockchain Operations with Our New n8n Community Node

We're excited to announce the launch of n8n-nodes-stellar, a powerful community node that brings Stellar blockchain automation to your n8n workflows!

## The Challenge

Blockchain integration has traditionally required extensive development resources and technical expertise. Whether you're processing payments, executing DEX trades, or interacting with Soroban smart contracts on Stellar, these operations typically demand custom code and ongoing maintenance. For teams leveraging n8n for automation, the lack of native Stellar support meant complex workarounds or abandoning no-code principles entirely.

## Meet n8n-nodes-stellar

Velocity BPA has developed n8n-nodes-stellar to bridge this gap, enabling seamless Stellar blockchain automation directly within your n8n workflows. This community node empowers you to build sophisticated blockchain-powered automations without writing a single line of code.

## Key Features

**Payment Operations**: Send and receive Stellar lumens (XLM) and other assets programmatically. Perfect for automated treasury management, payroll systems, or customer payment processing.

**DEX Trading**: Execute trades on Stellar's decentralized exchange, monitor order books, and manage trading strategies—all within your n8n automation workflows.

**Soroban Smart Contracts**: Interact with Soroban smart contracts, enabling complex blockchain logic integration with your existing business processes.

**Enterprise-Ready**: Built with reliability and security in mind, suitable for production environments and mission-critical workflows.

## Getting Started

Installation is straightforward. Simply run:


npm install n8n-nodes-stellar


Once installed, restart your n8n instance, and you'll find the Stellar node available in your node palette. The node comes with comprehensive documentation to help you get started quickly.
